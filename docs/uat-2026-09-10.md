## Functional notes

- Costing initially showed `no price` because the test product pack size was
  `1000.0 each` while the ingredient amount was in grams. Changing the pack size
  to `1000 g` made costing work. This is expected unit-mismatch behavior, not a
  costing-engine bug.
- Verified costs:
  - 1 item: `100 g`, `$0.25/batch`, `$0.25/item`
  - 2 items: `200 g`, `$0.50/batch`, `$0.25/item`
- Pantry entry verified: `Butter · 250.0 g · $3.00`.
- JSON backup/restore exists in `BackupManager` but has no user-facing UI in this
  build, so the UI checklist item is effectively N/A.
- OCR import reached the camera and produced an editable draft path. A captured
  non-recipe image produced `Could not read text from that image.`, which is
  expected for that test image.
